# Статистика отгрузок

Программа на Python для расчёта статистики по количеству паллет
в отгрузках.

## Функции

- `average_pallets(pallet_counts)` — среднее число паллет на отгрузку.
- `max_pallets(pallet_counts)` — максимальное число паллет среди отгрузок.
- `shipment_summary(pallet_counts)` — количество отгрузок, общее
  и среднее число паллет.
- `is_large_shipment(pallet_count, threshold=10)` — проверка,
  достигла ли отгрузка заданного порога.

Для пустого списка функции расчёта среднего и максимума возвращают 0.
Отрицательное количество паллет вызывает ошибку ValueError.

## Запуск программы

Выполнить из корневой папки проекта:

```powershell
python main.py
```

## Запуск тестов

```powershell
python -m unittest -v
```
